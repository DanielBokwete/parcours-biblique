# Parcours Biblique

Jeu gratuit pour parcourir toute la Bible (488 niveaux, Louis Segond 1910) et se défier en ligne.

- `index.html` : le jeu (solo + défis en ligne)
- `admin.html` : espace d'administration (comptes administrateurs uniquement)
- `bible-lsg.json` : texte de la Bible pour la lecture dans l'application
- `seed/questions.json` : banque de questions importable depuis l'espace admin

Base de données et comptes : Supabase (projet `parcours-biblique`).
